- [x] **LXNS API 文档调研**：阅读学习 [maimai.lxns.net/docs](https://maimai.lxns.net/docs)，对比 Diving-Fish API 差异
  - 关键发现：LXNS 使用结构化 `Notes` 对象（含 `total`）vs Diving-Fish `notes[]` 数组
  - Song 结构：LXNS 用 `difficulties: {standard, dx, utage}` 分离，Diving-Fish 用 `type`+"SD"/"DX" 标记
  - 枚举体系：LXNS 显式定义 `LevelIndex`(0-4)、`FCType`(app/ap/fcp/fc)、`FSType`(fsdp/fsd/fsp/fs)、`SongType`(standard/dx/utage)、`RateType`(sssp~d)
  - B50 响应：LXNS 含 `standard_total`/`dx_total` 预计算值 + `standard[]`/`dx[]` 列表
  - Player 画像：LXNS 提供 `friend_code`/`course_rank`/`class_rank`/`trophy`/`icon` 等完整字段
  - LXNS 优势：OAuth 第三方授权、曲目别名查询、Recent/AP 50、趋势图/热力图、资源 CDN
  - 决策：以 Diving-Fish 为主（免费无鉴权），LXNS 为玩家数据补充源，内部类型统一中性命名
  - 开放问题：SSR 渲染页面无法直接抓取，需通过 API 调用或参考 Wiki/搜索
