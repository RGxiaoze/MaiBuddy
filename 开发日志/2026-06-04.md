## 下午 — P0-P1 验收 Bug 修复

### Bug 1: 五维数值均为 0.99
- **根因**：公式 `Σ(s² × f) / Σ(s²)` 输出范围 [0.6, 1.0]，而不是 [0, 10]
- **修复**：改为三次加权 `Σ(s³ × f) / Σ(s²)`，输出覆盖 0-10 范围
- 涉及：`src/utils/dimensions.ts`

### Bug 2: 所有谱面被分类为 B15
- **根因**：`checkPool` 对两个池都检查，floor15 更低总是通过
- **修复**：按 `song.isNew` 版本标志约束池分配
- 涉及：`src/utils/rating.ts`

### Bug 3: 策略卡片 "15400+" 永无匹配
- **根因**：`parseInt("15400+")` max 值为 NaN
- **修复**：检测末尾 `+` → max=999999；知识库拆为 15400-16200 / 16200+ 两档
- 涉及：`scripts/build-kb.js` / `docs/knowledge-base.md`

### Bug 4: 推分建议目标过于激进
- **根因**：对所有玩家使用 100.5% 理论天花板
- **修复**：B50 天花板分析 + `realisticTargetAch()` 动态目标 + `MAX_LEVEL_GAP=1.5`
- 涉及：`src/utils/rating.ts`

### Bug 5: 语言风格网游化
- **修复**：宗师→Ranker、大神→ranker、极致手法→进阶手法、殿堂→Ranker档
- 涉及：`src/utils/strategy.ts` / `docs/knowledge-base.md`

### Bug 6: 在线查询切页清空
- **根因**：`useState('')` 不保留 Zustand 中的用户名
- **修复**：`useState(dfPlayerName)` + 移除重复声明
- 涉及：`src/pages/PlayerInfo.tsx`

### Bug 7: 直接 URL 访问 SongDetail 白屏
- **根因**：React Hooks 顺序违规 — `useMemo`/`useScoreStore` 写在 early return 之后，第一轮渲染未执行，第二轮新增 → `Rendered more hooks` 崩溃
- **修复**：将所有 hooks 移到 early return 之前，`allDiffs` 等衍生变量加 `song?` 空安全
- **验证**：Playwright 浏览器测试 — `/songs/11662` / `/songs/11385` / `/songs/999999` 全部正常
- 涉及：`src/pages/SongDetail.tsx` / `src/pages/SongList.tsx`

- 五维雷达图有区分度 ✓ | B15/B35 正确分类 ✓ | 推分建议不再推荐远超能力谱面 ✓ | 语言风格社区化 ✓ | 在线查询持久化 ✓ | SongDetail 直接 URL 可正常渲染 ✓
