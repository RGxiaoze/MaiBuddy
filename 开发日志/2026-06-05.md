## F1-F4 批量修复 + F5 加权难度分类

### F1：DF 查询后推分建议不可见
- **根因**：`PushSuggestions` 组件渲染在 `activeTab === 'local'` 分支内，DF 查询时分支为 `false`
- **修复**：将 `<PushSuggestions>` 提升到两标签页结构之外

### F2/F4：移除高亮相关 UI
- 移除列高亮下拉框、蓝色底色、行高亮，三列平等显示

### F3：估算标记优化
- `~` → 灰色 `?` + cursor-help + tooltip 释义
- 估算行"当前"列加 `估` 前缀（如 `估 98.3%`），加 `whitespace-nowrap` 防止换行
- 无本地成绩时表格上方显示黄色提示框，引导用户导入完整成绩

### 💎 emoji 全部移除
- Sidebar.tsx 两处、MobileHeader.tsx 一处，替换为无装饰文字

### 定数区间策略大修（zone 扩展）
- **旧**：`mode + 0.1 → mode + 0.5`（maxscore 仅 1 个谱面在区间内）
- **新**：`mode - 1.0 → mode + 0.5`（B35/B15 统一下限）
- **B15 缺员例外**：`best15.length < 15` 时下限收紧到 `mode - 0.5`，避免推荐黄/绿谱
- `TARGET_GAP_CLOSE/MODERATE/FAR` 阈值同步放宽（0.3→0.5, 0.5→1.0, 1.0→1.5）

### 术语统一
- 全部 `全量成绩` → `完整成绩`（10 个文件）

### F5：加权难度分类
- `classifyDifficulty(score, stats?, targetAchievements?)` 新增可选参数
- **有 chart_stats + targetAchievements**：社区分（60%）+ gap 分（40%）加权
  - 社区分 = `(diffFromLevelAvg + 5) / 10`，clamp [0,1]
  - gap 分 = `1 - (targetAch - currentAch) / 15`，clamp [0,1]
  - 复合分 ≥ 0.65 → easy, ≥ 0.35 → medium, < 0.35 → hard
  - SSS+ 率提升、15级永远 hard 规则不变
- **无 chart_stats + targetAchievements**：达成率分档 + gap > 5% 降一级
- `pushSuggestions.ts` 两处调用传入 `100.5` 作为 gap 基准
- 推分建议表格下方描述同步更新
