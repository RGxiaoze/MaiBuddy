## 一、落雪（LXNS）账号接入

首次真正跑通落雪链路，实测暴露四处对接错误，均已修复：

| 问题 | 错误做法 | 正确做法 |
|------|----------|----------|
| token / revoke 端点 | 根路径 `/oauth/*` → 405 | `/api/v0/oauth/{token,revoke}` |
| 个人 API 密钥请求头 | `Authorization: Bearer` → 401 | `X-User-Token` |
| 响应结构 | 当裸数组 → 永远空 | 取信封里的 `data` |
| 曲目 ID 字段 | 只认 `song_id` → 成绩全丢 | 兼容 `id` |

**DX 谱面 ID 换算**：本曲库沿用水鱼的「DX = 基础 + 10000」独立条目，
落雪用同一 ID + `type` 区分，查询前必须换算，否则 81 条 DX 新曲全部丢失
（表现为「B15 只有 2 首」）。

**Rating 取整**：落雪 `dx_rating` 是 8 位小数浮点，舞萌是整数相加。
源头（`toDfScores`）与读取（`computeB50`）都取整，旧数据无需重导。
实测复算：B35 11439 + B15 4791 = **16230**，与落雪一致。
