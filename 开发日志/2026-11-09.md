## 一、落雪（LXNS）账号接入

首次真正跑通落雪链路，实测暴露四处对接错误，均已修复：

| 问题 | 错误做法 | 正确做法 |
|------|----------|----------|
| token / revoke 端点 | 根路径 `/oauth/*` → 405 | `/api/v0/oauth/{token,revoke}` |
| 个人 API 密钥请求头 | `Authorization: Bearer` → 401 | `X-User-Token` |
| 响应结构 | 当裸数组 → 永远空 | 取信封里的 `data` |
| 曲目 ID 字段 | 只认 `song_id` → 成绩全丢 | 兼容 `id` |

**DX 谱面 ID 换算**：本曲库沿用水鱼的「DX = 基础 + 10000」独立条目，
落雪用同一 ID + `type` 区分，查询前必须换算，否则 81 条 DX 新曲全部丢失
（表现为「B15 只有 2 首」）。

**Rating 取整**：落雪 `dx_rating` 是 8 位小数浮点，舞萌是整数相加。
源头（`toDfScores`）与读取（`computeB50`）都取整，旧数据无需重导。
实测复算：B35 11439 + B15 4791 = **16230**，与落雪一致。

## 八、其他

- 背景切换改为双图层交叉淡入（300ms）
- `formatGain()`：收益取整，不再出现 `+13.0`
- **更新记录改为静态内联**：原先运行时 `fetch('changelog.json')`，但 CI 走
  `npx vite build` 不触发 `prebuild`，产物里没有该文件 → 线上 404。
  现由 `gen-changelog.js` 生成 `src/data/changelog.generated.ts` 并直接 import；
  工作流同步改为 `npm run build` + `fetch-depth: 0`（否则更新记录只剩 1 条提交）
- **更新记录排版**：按天折叠（默认 4 条，其余「展开其余 N 条」）；
  咬文嚼字类小修（文案/措辞/笔误/排版/命名/注释）不再单独占卡片，
  归入「细节修正 N 项」一行，需要时才展开
- **五维特征文件线上 404**：`featureService` 运行时 fetch `data/simai_features.json`，
  该文件由 `extract-features.ts` 手动生成且被 gitignore，CI 从不产生 →
  线上一直拿不到谱面特征却照常渲染。改为提交 gzip 版（4.5 MB → 872 KB），
  前端用 `DecompressionStream` 解压，失败再回退到未压缩版（本地开发路径）
- **推分难度标签补上「玩家差距」**：好友反馈「98.7% → 100.5%（+19 分）被标成轻松」。
  根因是调用 `classifyDifficulty` 时**没传目标值**，走了「只看全服数据」的分支。
  现在传入实际目标（收益最大的那一档），并新增差距下限：
  差距 > 1.0% 至少「适中」，> 3.0% 直接「挑战」——与全服信号无关
- **方案 C：目标改成「按自己的水平」**：新增 `typicalAchievement()` 取玩家 B50 中
  ±0.3 定数段成绩的中位数（样本 < 5 条则不信，退回档位规则），
  `realisticTargetAchFor()` 把目标压到 `min(档位天花板, 中位数 + 0.5)`。
  效果：B50 里 14.1 的谱普遍只打 98% 的玩家，不会再被推 100.5%
- **定数上限改以 B1 为锚**：原 `mode±` 规则换成 `B1 + 0.2`（B1 = B50 里 Rating 最高的一条，
  跨两池取）。`fit_diff` 比官标低 ≥0.3 的「特简单」谱可放宽到 `B1 + 0.4`，
  且目标封顶 100.0%（鸟），不推鸟加。无 B50 时退回旧规则。
  新增纯函数 `computeRecommendCaps()` / `isSimpleChart()` 便于测试
- **B15 拟合定数去偏**：隐藏/联动区域曲目只有解锁玩家会打，样本偏斜导致
  `fit_diff` 系统性偏低（例：アメリスト 官标 13.9 → 拟合 13.62）。现采集
  `chart_stats.cnt` 作为样本量，按「同官标档中位数 × 0.5，且 ≥ 20」判定可信度：
  - 不可信样本不参与「特简单」破顶判定
  - 同收益排序时靠后，避免刷屏
  - 曲目详情展示样本量与「参考价值有限」提示
  - B15（新版本）典型拉伸从 0.5 收紧到 0.3
