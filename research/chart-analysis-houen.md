# 谱面分析 — 封焔の135秒[DX] (Re:MASTER 14.8) 修订版

> BPM: 200（尾段 160）× 4/4 拍

## 术语约定（社区用语）

| 术语 | 含义 |
|------|------|
| **单双** | 单 note → 双押 → 单 note → 双押 交替 |
| **8 分纵连** | 八分音符间隔的同一键位或邻键连续击打 |
| **位移交互** | 需要双手动线配合的交替击打，速度决定打法（快→扫，慢→交互） |
| **折返扫键** | 从上往下扫再原路从下往上扫回的扫键，另一只手通常被占用 |
| **圈** | 绕行半周以上的连续按键序列 |
| **Ex 星星** | 仅星星头部为 Ex 判定，身体普通 |
