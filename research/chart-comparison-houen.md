# 谱面对比 — 封焔の135秒[DX] 三难度

> Expert (12.7) / Re:Master (14.8) 同 BPM 200→160 结构

## 配置演进（Re:Master → Expert → Advanced）

| 配置 | Re:Master 14.8 | Expert 12.7 | Advanced 8.8 |
|------|:--:|:--:|:--:|
| Slide 类型数 | 9 | 4（直线/方向/W/Ex） | 2（直线/方向） |
| 反向双 Slide | 4 次 | 0 | 0 |
| 平行双星星 | 2 次（Break + Ex） | 0 | 0 |
| PP/QQ/V-fold | 各 2-6 次 | 0 | V-fold 1 次 |
| Touch 多押 | B4/B5/E5 三连 | 无双押 Touch | 无双押 Touch |
| Touch Hold (C1h) | 1 次 | 0 | 0 |
| C1f 烟花 | 9 次 | 1 次（结尾） | 0 |
| Break 密度 | 极高（全 Break 段 + Break Slide） | 中（散落 Break 双押） | 低（点缀 Break） |
| Ex Note | Ex Tap + Ex Slide + Ex Hold | Ex Tap + 少数 Ex Slide | Ex Tap 点缀 |
| 32 分爆发 | 多次 | 0（最快 16 分） | 0（最快 8 分） |
| 48 分细分 | 有 | 0 | 0 |
| 圈 | 1 次完整圈 | 0 | 0 |
| 折返扫键 | 有 | 0 | 0 |
| 12 分位移交互 | 有 | 有（12 分跳拍） | 0 |
| 384 分休息段 | 有（10 秒+） | 0 | 0 |
| 结尾 | 平行绝赞星星 | Ex Slide + C1f | Hold + Break 双押 |

## Expert 12.7 特征

Expert 保留了 Re:Master 的**骨架**（BPM 结构、段落划分、主旋律对应），但大幅削减了复杂度：

- **Slide**：仅保留直线 Slide + 方向 Slide（`<`/`>`）+ 少量 W Slide。V-fold/PP/QQ 全部移除
- **Hold 交替段**：降为 16 分短 Hold（等同于 Re:Master 的简化版）
- **休息段**：没有 96/384 分长休息——用简单的空拍替代
- **Touch**：仅保留单点 Touch（E1-E6, B4-B5），无多押
- **结尾**：BPM 160 退场 + C1f，无平行星星

Expert 的定位是"能打完 Re:Master 的主体节奏但不具备处理复杂 Slide 的能力"。

## Advanced 8.8 特征

Advanced 是**入门级**——每个难点只保留最简单版本：

- 每小节最多 4 个音符（四分），最高密度仅八分
- Slide 全是单段直线/方向 Slide，间隔充足
- Break/Ex 仅作为点缀出现（每段 1-2 次）
- Touch 仅出现在段落切换处
- 无圈、无扫键、无位移交互
- 结尾：Hold + Break 双押，无 C1f
