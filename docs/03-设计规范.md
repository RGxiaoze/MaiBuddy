# 设计规范 — 舞萌DX 伴侣

## 色彩系统

### 背景层级
| 用途 | 色值 | 说明 |
|------|------|------|
| 页面底色 | `#F4F6FA` | 极淡冷灰，与正文对比度 16:1 |
| 卡片/侧边栏 | `#FFFFFF` | 纯白 |
| 浮层 | `#EEF2FF` | 微蓝紫 |
| 次级灰底 | `#EBEEF3` | 次要区块 |

### 品牌色
| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#5BA4CF` | 按钮、链接、选中状态（需 ≥14px bold 满足对比度） |
| 主色浅 | `#A8D8F0` | 背景装饰、浅底强调 |
| 主色深 | `#3D8BB8` | hover/active 态 |
| 次要色 | `#B8A0E8` | 淡紫，次要区块背景 |
| 强调色 | `#6C4DBF` | 深紫，小面积点缀（徽章、图标、渐变尾色） |

### 文字
| 用途 | 色值 | 说明 |
|------|------|------|
| 正文 | `#1A1C2E` | 近黑藏蓝，白底对比度 16.5:1 |
| 次要文字 | `#5E6778` | 中灰，对比度 5.8:1 |
| 辅助文字 | `#8B93A5` | 浅灰，仅 ≥14px 使用 |

### 语义色
| 用途 | 色值 | 说明 |
|------|------|------|
| 成功 | `#1E9E4A` | 白底对比度 4.6:1 |
| 警告 | `#D97706` | 白底对比度 4.5:1 |
| 错误 | `#DC2626` | 白底对比度 4.8:1 |
| 信息 | `#2563EB` | 白底对比度 5.2:1 |

### 边框
| 用途 | 色值 |
|------|------|
| 默认边框 | `#DEE3EA` |
| 浅边框 | `#E5E9F2` |

## 排版

| 属性 | 值 |
|------|------|
| 标题字体 | `'M PLUS Rounded 1c', 'Inter', sans-serif` |
| 正文字体 | `'Inter', 'Noto Sans SC', -apple-system, sans-serif` |
| 基准字号 | 14px |
| 标题 | 18px / 16px / 15px |
| 行高 | 1.5 |
| 圆角 | 8px（卡片）、6px（按钮/输入框）、4px（标签） |

## 布局

- **桌面端**：左侧可折叠侧边栏(展开 220px / 折叠 64px) + 右侧主内容区(flex-1)
- **移动端**：顶部汉堡菜单 + 滑出侧边栏 + 底部导航栏
- 最大内容宽度：`max-w-4xl` ~ `max-w-6xl`
- 4pt 间距系统（Tailwind 默认）

## 组件规范

### 按钮
- 主按钮：主色背景 + 白色文字 + 圆角 6px
- 次要按钮：主色边框 + 透明背景 + 主色文字
- 危险按钮：红色文字 + 红色边框
- 触摸目标 ≥ 44px

### 输入框
- 白色背景 + 边框 `#DEE3EA`（默认）→ `#5BA4CF`（聚焦）
- 圆角：6px，内边距：8px 12px

### 卡片
- 白色背景 + 边框 + 轻微阴影 `shadow-sm`
- 圆角：8px

### 模态框
- 居中 overlay + 半透明黑色遮罩
- 白色卡片 + 圆角 12px
- 最大宽度 520px

### 图标
- 使用 Lucide SVG 图标库，禁止 emoji 作为图标
- 统一 20px/16px 尺寸

## 设计原则
1. 简洁优先 — 避免多余装饰和动画
2. 信息密度适中 — 不拥挤也不稀疏
3. 操作路径短 — 减少点击层级
4. 状态可见 — 加载/空数据/错误均有明确提示
5. 颜色语义化 — 评级和难度用颜色快速区分
6. 响应式优先 — 桌面/移动端均有合理布局
