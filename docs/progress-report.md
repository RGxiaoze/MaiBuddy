# 项目进度报告 — MaiBuddy（舞萌DX 伴侣）

> 更新日期：2026-06-10 | 当前版本：v0.4.1

## 一、已完成功能

### 基础架构
- React 19 + TypeScript + Vite + TailwindCSS v4 + Zustand + Dexie.js 技术栈
- IndexedDB 本地存储（成绩、曲目缓存、别名、chart_stats）
- 暗色模式、响应式布局（桌面侧边栏 + 手机底部导航）

### 曲目与成绩
- 多关键词搜索（曲名/作者/谱师/别名）、定数/版本/难度筛选、分页浏览
- 曲目详情（DX Rating 对照表、全服达成率三行对比）
- 手动录入/编辑/删除成绩、Diving-Fish 完整成绩批量导入
- B50 分析（Best35 + Best15）、DX 星数展示、B15 空位提醒

### 推分与策略
- 推分建议（三档目标 SS+/SSS/SSS+，B35/B15 双池独立 30 上限，配置标签：底力/爆发/技巧/综合）
- 预览模式：折叠态显示前 5 条 + 渐变虚化遮罩
- 定数阶梯策略（10 段数据驱动，基于 Rating 公式反推 B50 均分）
- 推分路线规划（4 阶段定数区间，水分曲优先）

### 五维分析（当前版本 — 物量统计）
- 底力/体力/爆发/定位/技巧 立方加权评分 + ECharts 雷达图
- 统计指标卡片（AP 数/SSS+ 数/Rating 进度/定数分布）
- 谱面类型适应性分析（9 种标签：交互/纵连/星星/跳拍/体力/技巧/综合/扫键/Touch）
- 定数阶梯策略卡片

### 工具与页面
- 使用指南、更新记录、开发文档页面
- 侧边栏关于区（致谢/数据来源/参考项目/技术栈）
- Footer + GitHub 链接
- 导入进度反馈、B15 空位提醒
- GitHub Pages 部署（CI/CD 自动构建）

### 知识库与研究
- simai 谱面格式完整学习（5 种 Note × 6 传感器区 × 12 Slide 路径）
- 机台布局几何模型（6 层区域：按键→A→D→E→B→C，来源 AstroDX 源码）
- 社区拍数命名规则（拍号÷逗号数）
- 星星时值公式（来源 simai-sharp-ts SlideReader.ts）
- 体力/爆发/切换成本模型（肩膀+小臂双池、等效 BPM、三档恢复）
- 配置分类表 11 种 + 术语词典 32 条
- 三首 14+ 谱面详细分析（封焔/Schwarzschild/Sqlupp）

## 五、v0.4.1 修复汇总 (2026-06-10)

- **渲染安全**: `ErrorBoundary` 包裹 `Outlet`，防止单页面崩溃全站白屏
- **并发安全**: `statsService` Promise 队列替代轮询，消除活锁风险
- **内存泄漏**: `SongDetail` useEffect 添加 cancelled 清理标志
- **性能优化**: `SongList` pairMap 独立 useMemo、`PlayerInfo` totalNotesMap 预建
- **算法修复**: B35 下界渐进放宽 + 扫描标准谱面 + 每池独立上限(30)
- **UI 优化**: B35/B15 预览 5 条虚化 + 导入弹窗垂直表单 + body 滚动锁定
- **统计修复**: `forceRefreshStats` 原地重建数据，不再清内存导致组件数据消失
- **类型安全**: 补全 `SortBy` 类型、移除非空断言、清理未使用变量
- **开发者文档**: 新建 `ARCHITECTURE.md`（模块依赖图+数据流+配置速查+常见修改）
