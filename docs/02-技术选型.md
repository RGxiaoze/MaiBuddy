## 为什么不选

| 方案 | 不选原因 |
|------|----------|
| Electron | 需安装客户端，与"浏览器即用"目标冲突 |

| SASS/Less | TailwindCSS v4 已覆盖原子化 + 主题变量需求 |

## API 依赖

### Diving-Fish API（主数据源）

**基础 URL**：`https://www.diving-fish.com/api/maimaidxprober`

**API 文档**：https://maimai.diving-fish.com/manual/docs/developer/zh-api-document

| 端点 | 方法 | 认证 | 用途 | 调用时机 |
|------|------|------|------|----------|
| `/music_data` | GET | 无需 | 曲目元数据 | 首次进入曲目页 |
| `/chart_stats` | GET | 无需 | 全服统计（拟合难度等） | 曲目详情页（可选） |
| `/query/player` | POST | 无需 | 玩家简略成绩（B50/B40） | 玩家信息页在线查分 |
| `/player/records` | GET | Import-Token | **玩家完整成绩（全量）** | 一键导入完整成绩 |
| `/dev/player/records` | GET | Developer-Token | **玩家完整成绩（全量，可查任意用户）** | 一键导入完整成绩（备选） |
| `/dev/player/record` | POST | Developer-Token | 单曲成绩查询 | 按需（可选） |
| `/query/plate` | POST | 无需 | 按版本获取成绩 | 可选 |

#### 认证方式说明

| 方式 | 获取途径 | 适用场景 |
|------|---------|----------|
| **无需认证** | — | 歌曲数据、B50 查询 |
| **Import-Token** | 用户在 Diving-Fish 个人资料页自行生成 | 个人工具，拉取自己的完整成绩 |
| **Developer-Token** | 开发者向 Diving-Fish 申请 | 多用户服务，可查任意用户的完整成绩 |

#### 关键注意事项
- `/query/player` 需在请求体传 `b50: true` 才能获取 B50，否则默认返回 B40
- `/player/records` 返回**所有曲目 × 所有难度**的成绩，数据量大，仅用于导入存储
- Diving-Fish 使用 `username` 或 `qq` 作为玩家标识（无 `friend_code` 概念）
- 玩家不存在时返回 HTTP 200 + `{"message":"user not exists"}`，需手动检查

### LXNS API（未来兼容，暂未实现）

**基础 URL**：`https://maimai.lxns.net/api/v0/`

| 端点 | 方法 | 认证 | 用途 |
|------|------|------|------|
| `/maimai/song/list` | GET | 无需 | 曲目列表（含物量、分类、版本） |
| `/maimai/player/{friend_code}` | GET | Developer-Token | 玩家画像（段位、称号、头像） |
| `/maimai/player/{friend_code}/scores` | GET | Developer-Token | 完整成绩（简化后） |
| `/maimai/player/{friend_code}/best` | GET | Developer-Token | 每谱面最佳成绩 |

- 鉴权：`Authorization` 头（开发者 API 密钥）或 `X-User-Token`（个人 Token）
- LXNS 使用 `friend_code`（15 位数字）作为玩家唯一标识
- LXNS 完整成绩需要玩家在查分器设置中开启 `allow_third_party_fetch_scores` 权限
- 内部类型统一使用中性命名，服务层做格式转换

### 社区别名 API（辅助，v0.3.0+）

**来源**：[Yuri-YuzuChaN/maimaiDX](https://github.com/Yuri-YuzuChaN/maimaiDX) 社区别名数据库

| 端点 | 方法 | 认证 | 用途 |
|------|------|------|------|
| `https://www.yuzuchan.moe/api/maimaidx/maimaidxalias` | GET | 无需 | 曲目别名列表（SongID → Name + Alias[]） |

- 通过 Vite 代理 `/alias-api` → `https://www.yuzuchan.moe/api` 访问
- 加载策略：IndexedDB 缓存（24h TTL）优先 → API 获取 → 构建反向索引 `Map<lowercase_alias, songId[]>`
- 匹配策略：子串包含匹配（`alias.includes(query)`）
- 失败处理：API 不可用时报告用户，搜索降级为仅 title/artist/noteDesigner
