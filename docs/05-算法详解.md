## 1. API 数据格式（要点）

### 1.1 Diving-Fish 曲目数据

端点：`GET https://www.diving-fish.com/api/maimaidxprober/music_data`

关键字段：
- `basic_info.is_new` — B50 版本判定的核心字段（`true`=新版本，`false`=旧版本）
- `charts[].notes[]` — 物量数组：SD=[TAP, HOLD, SLIDE, BREAK]，DX=[TAP, HOLD, SLIDE, TOUCH, BREAK]
- `ds[]` — 各难度定数 [BAS, ADV, EXP, MAS, ReMAS]
- 封面图 URL：`https://www.diving-fish.com/covers/{id_补零5位}.png`（ID 在 10001-11000 时减 10000）

### 1.2 Diving-Fish 玩家成绩

端点：`POST https://www.diving-fish.com/api/maimaidxprober/query/player`

请求体：`{ username: string }`，私密用户需额外带 header `developer-token: <token>`。403 = 需要 Token。

### 1.3 LXNS API

| 端点 | 用途 |
|------|------|
| `GET /api/v0/maimai/song/list?notes=true` | 曲目列表（Notes 对象含 total，非数组） |
| `GET /api/v0/maimai/player/{friend_code}/bests` | B50（预计算 standard_total/dx_total） |

枚举对照：

| 概念 | Diving-Fish | LXNS |
|------|------------|------|
| 难度索引 | 隐式数组索引 | `LevelIndex`: 0=BASIC~4=ReMAS |
| 谱面类型 | `"SD"`/`"DX"` | `"standard"`/`"dx"` |
| FC 状态 | `""`/`"fc"`/`"fcp"`/`"ap"`/`"app"` | 同，但空值为 `null` |
| DX Rating 字段 | `ra` | `dx_rating` |
| 物量字段 | `notes[]` 数组 | `Notes` 对象（含 `total`） |

## 2. Rating 计算

### 2.1 公式

```
单曲Rating = floor(谱面定数 × 等级系数 × min(达成率, 100.5%))
```

等级系数是独立的分段函数，不是简单的 `达成率/100`。

### 2.3 达成率计算公式

```
达成率 = (基础分 / 理论最大基础分) × 100% + (BREAK加分 / 理论最大BREAK加分) × 1%
```

音符权重：TAP/TOUCH×1, HOLD×2, SLIDE×3, BREAK×5。理论最大 = 全 Critical Perfect → 101.0000%（有效上限 100.5%）。

## 3. B50 算法

```
总 DX Rating = Best35(旧版本) + Best15(新版本)
```

**流程**：
1. 遍历所有成绩，取每个谱面 (songId + levelIndex) 的最高分
2. 通过 `basic_info.is_new` 分为新旧版本两池
3. 两池各自按 Rating → 定数 → 达成率 降序排列
4. 旧版本取前 35 首，新版本取前 15 首
5. 总 Rating = Best35 + Best15

**排除规则**：宴会场 (songId ≥ 100000) 不计入。达成率 < 10% 的成绩 Rating 为 0。

## 4. 五维评分（方案 C）

### 4.1 维度定义

| 维度 | 含义 | 核心指标 |
|------|------|----------|
| 底力 | 高速高密度谱面的即时读谱与执行能力 | BPM × 总物量 ÷ 曲长 |
| 体力 | 长时间持续高负荷的耐力 | 总物量 × 曲长 |
| 爆发 | 极高峰值密度段的冲击处理能力 | BPM × 10s 窗口峰值密度 |
| 定位 | 宽广屏幕范围准确触击目标位置 | (TOUCH + SLIDE×1.5 + HOLD×0.8) ÷ 总物量 |
| 技巧 | SLIDE折返/TOUCH阵/HOLD复杂度等非标准配置 | (SLIDE×1.2 + HOLD + BREAK + TOUCH×1.1) ÷ 总物量 |

### 4.2 归一化

`normalize(raw, max) = Math.min(raw / max * 18, 18)` — 缩放到 18，与谱面定数体系对齐（超规格 15 谱面在关键维度可达 15+）。

### 4.3 玩家能力计算

```
个人维度能力分 = Σ[ 谱面维度分² × 达成率映射值 ] / Σ[ 谱面维度分² ]
```

- 仅计入达成率 ≥ 97% 的成绩（表示该谱面已被有效掌握）
- 平方加权：谱面维度分越高，对能力分的贡献越大
- 达成率映射（非线性）：

| 达成率 | 97% | 98% | 99% | 99.5% | 100% | 100.5% |
|--------|-----|-----|-----|-------|------|--------|
| 映射值 | 0.6 | 0.7 | 0.8 | 0.9 | 0.95 | 1.0 |

> 实现代码：`src/utils/dimensions.ts`

## 6. DX 星数评分

### 6.1 判分规则

DX Score（DX 分数）是独立于达成率（Achievement）的判定精度指标，所有 Note 类型统一计分：

| 判定 | DX 分数 |
|------|---------|
| Critical Perfect | 3 |
| Perfect | 2 |
| Great | 1 |
| Good / Miss | 0 |

> **关键区别**：与达成率体系不同，DX 分数中 **Slide 没有 3 倍加成**，**Break 没有细分判定档**，所有音符一律平等。

### 6.2 EX 保护 Note

EX-TAP / EX-HOLD / EX-TOUCH 等保护 Note 在 DX 分数中为**二值判定**：
- 命中判定区 → **Critical Perfect（3 分）**
- Miss → **0 分**
- **不存在** Perfect(2) / Great(1) / Good(0) 中间判定

但**理论最高 DX 分数不受影响**——全 CP 状态下 EX 与非 EX note 得分相同（均为 3 分/note）。

### 6.3 理论最高值

```
理论最高 DX 分数 = 谱面总物量 × 3
```

### 6.4 星数阈值

DX 分数率 = 实际 DX 分数 ÷ 理论最高 DX 分数 × 100%

| DX 分数率 | 星数 | 内部标识 |
|-----------|------|---------|
| ≥ 97% | ⭐⭐⭐⭐⭐ | `dxStar5` |
| ≥ 95% | ⭐⭐⭐⭐ | `dxStar4` |
| ≥ 93% | ⭐⭐⭐ | `dxStar3` |
| ≥ 90% | ⭐⭐ | `dxStar2` |
| ≥ 85% | ⭐ | `dxStar1` |
| < 85% | — | `dxStar0` |

社区延伸标准（非官方，不在展示中体现）：≥99% → 六星，100% → 七星。

### 6.5 实现

计算函数位于 `src/utils/dxStar.ts`：

- `computeDxStar(dxScore, totalNotes)` → `{ ratio, stars, maxDxScore }`
- `renderStars(stars)` → ⭐ 字符串

展示位置：
- **谱面详情页**（SongDetail）：每条成绩行显示 `DX {score}/{max} ({ratio}%)`
- **B50 一览**（PlayerInfo）：每条 B50 行显示 `⭐ {ratio}%`
