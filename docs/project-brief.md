# 舞萌DX 伴侣 — 项目概要与合作交流文档

> 用途：与其他开发者（或他们的 AI agent）快速对齐项目背景、定位、技术栈与当前状态。
> 更新：2026-08-05 | 版本：v0.4.1（五维校准进行中）

## 一、项目定位

**舞萌DX伴侣**（MaiBuddy）是一个面向 maimai DX（舞萌DX）玩家的**个人数据与分析工具**，核心差异化是：

1. **五维能力分析**：底力/体力/爆发/定位/技巧，玩家能力画像（雷达图）
2. **谱面位移驱动五维**：解析 simai 谱面 → 提取音符时空坐标 → 计算位移/速度/体力消耗 → 客观五维评分（**全生态独有**）
3. **推分建议与路线规划**：B35/B15 双池、三档目标、定数阶梯策略、水分曲优先

## 二、技术栈

React 19 + TypeScript + Vite + TailwindCSS v4 + Zustand + Dexie(IndexedDB) + ECharts

- 数据源：Diving-Fish 查分器 API（成绩/曲库/chart_stats）、LXNS CDN（simai 谱面/曲绘/音频）
- 解析器：simai-sharp（TS 移植版）
- 部署：GitHub Pages（CI/CD）

## 四、五维算法（进行中）

**目标**：五维分值改为 1.0-15.0，与定数贴合。采用**基准谱面监督校准**方案：

```
raw特征(算法输出) → 校准映射 → target(1.0-15.0)
                          ↑
                    基准谱面人工标注
```

- **下界锚点**：ツギハギスタッカート（拼凑的断音），定数 1.0，五维全 1.0
- **上界锚点**：≥14.7 定数 46 首候选（QZKago Requiem / PANDORA PARADOXXX 等多维领先）
- **映射**：逐维度线性回归（待人工标注后拟合）

算法核心（已实现）：
- 坐标模型：6 层区域（按键→A→D→E→B→C），归一化半径
- 底力：实际帧间隔 + 模式类型（交互=16分基准/双押纵连=8分）→ 等效 BPM
- 体力：双池（肩膀/小臂）+ 舒适区 + Touch×0.3 + 环形Slide×0.5
- 爆发：多窗口双因子（位移+密度）扫描
- 定位：5a 高密度速度 + 5b 方向加权跳跃
- 技巧：三层（Path/Composite/Special）6 子要素
