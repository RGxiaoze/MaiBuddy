# 谱面分析 — 数据格式约定

## 文件来源

- **CDN**: LXNS CDN (`assets2.lxns.net/maimai/chart/{id}.txt`)
- **备用源**: Maichart-Converts GitHub (按分类目录组织)

## 文件统计

| 指标 | 值 |
|------|-----|
| 总数 | 1298 首 |
| SD 谱面 | 541 首 |
| DX 谱面 | 756 首 |
| 未知类型 | 1 首 (无 `&title=` 元数据) |

## 文件格式

### 元数据头 (以 `&` 开头)
```
&title=曲名 [SD]    # 曲名 + 类型标记
&artist=作者
&genre=分类
&version=版本
&music_id=ID        # LXNS 内部 ID，不一定等于 Diving-Fish 的 songId
&bpm=150.0
&pvstart=2.5        # PV 开始时间（秒）
&pvend=10.42        # PV 结束时间
```

### 难度标记
```
&lv_0=4             # Basic，levelIndex=0
&base_0=4.0         # 定数
&inote_0=           # 谱面数据开始
(150){1},,,         # simai 记号
...
E                   # 谱面结束
```

- `lv_0` ~ `lv_4` 对应 Basic / Advanced / Expert / Master / Re:Master
- `base_N` 为对应定数（浮点数）
- `inote_N=` 后紧跟谱面数据，以 `E` 结束

### 编码

- UTF-8（无 BOM）
- 换行符: `\n` (LF)

### 文件命名

- 下载后: `{LXNS_id}.txt` → 重命名为 `{曲名}[{类型}].txt`
- 例: `834.txt` → `PANDORA PARADOXXX[SD].txt`

## 特殊变体

| 情况 | 处理 |
|------|------|
| `&title=` 不在第一行 | 搜索前 30 行（如 11422.txt） |
| 无 `&title=` | 保留原始 LXNS ID 命名 |
| 宴会場 (Utage) | music_id ≥ 100000，排除 |
