# 需求规格 — 舞萌DX 伴侣

## 项目概述
开发一个运行在浏览器中的舞萌DX辅助工具（单页应用），用于曲目信息检索、个人成绩管理、B50分析和推分建议。

## 用户故事

### US-01 曲目检索
作为舞萌玩家，我希望能搜索和筛选游戏中的所有曲目，查看每首曲目的详细信息（定数、谱面、DX Rating），以便了解曲库全貌。

### US-02 成绩管理
作为舞萌玩家，我希望能手动录入自己的游玩成绩（达成率、评级、FC/AP等），并能查看、编辑、删除已有成绩，以便追踪个人进步。

### US-03 玩家信息与B50
作为舞萌玩家，我希望能查看自己的B50列表和总Rating，了解当前游戏水平的量化评分。

## 玩家成绩导入方式

### 手动录入（已实现）
用户在曲目详情页手动输入达成率、评级等，存入 IndexedDB。

### Diving-Fish 一键导入全量成绩（待实现）
- **接口**：`GET /api/maimaidxprober/player/records`（需认证）
- **认证方式**：用户自行在 Diving-Fish 个人资料页生成 `Import-Token`，填入 App
- **数据范围**：拉取该玩家**所有曲目 × 所有难度**的成绩（非仅 B50）
- 导入后自动基于全量成绩重新计算 B50 并刷新展示

### 未来兼容
- 预留 LXNS（落雪）查分器接入能力，认证方式为 `X-User-Token` 或开发者 API 密钥
- LXNS 全量成绩接口：`GET /api/v0/maimai/player/{friend_code}/scores`

### US-04 五维分析
作为舞萌玩家，我希望能看到自己在手速/耐力/定位/技巧/记忆五个维度的能力雷达图，了解自己的强项和弱项。

### US-05 推分建议
作为舞萌玩家，我希望系统能根据我的成绩推荐可提升Rating的谱面，并给出针对弱项的练习建议。

## 功能范围

### 阶段一：基础架构
- 曲目列表页（搜索 + 高级筛选）
- 曲目详情页（基础信息 + 谱面信息 + DX Rating + 成绩模块）
- 成绩录入/编辑/删除功能（手动，存储于 IndexedDB）
- 左侧导航栏框架（三个页面入口）

### 阶段二：数据联网与统计
- 对接 Diving-Fish API（曲目数据、全服统计、玩家成绩）
- B50 算法实现
- 玩家信息页（B50 列表 + 总 Rating）
- 五维分析界面雏形

### 阶段三：推分建议（基础版）
- 基于 B50 分析推荐可提升 Rating 的谱面
- 按预期提升幅度排序

### 阶段四：五维雷达图 + 进阶推分
- ECharts 雷达图可视化
- 维度代表谱面展示
- 高分推荐 / 低分练习曲

## 非功能需求
- 无需安装，浏览器打开即用（部署于 GitHub Pages）
- 无需后端服务器
- 数据本地存储（IndexedDB），用户隐私安全
- 适配桌面端浏览器（主要为 PC 端使用）
- 网络异常时给出友好提示，不崩溃
