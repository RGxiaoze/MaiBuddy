## 阶段四：五维算法优化

> **背景**：P0-P1 验收后，五维雷达图已修复为有区分度的正五边形（`Σ(s³×f)/Σ(s²)` 三次加权）。但当前算法存在三个根因导致无法区分高端玩家（普通万六/万六五/理论Rating/舞神）。

### 根因分析

| 问题 | 说明 |
|------|------|
| 体力公式反直觉 | `stamina = total²/BPM×60` — 同物量下低 BPM 反而体力分更高 |
| 爆发公式忽略密度 | `burst = BPM²/40` — 与物量完全无关，100 note 和 2000 note 同分 |
| 聚合过于粗糙 | 立方加权 + 6 档达成率因子，万六和舞神雷达图几乎重叠 |

### P0：数值统计指标（P3 优先）

在不改五维算法本身的前提下，增加可量化区分指标：

- [ ] **AP 计数**：`fcType='ap'|'app'` 数量。舞神 >50，普通万六 <10
- [ ] **SSS+ 计数**：`achievements >= 100.5` 的谱面数
- [ ] **Rating 进度**：`totalRating / theoreticalMaxRating × 100%`
- [ ] **定数区间分布**：按 13.x / 14.x / 15.x 分组统计平均达成率
- 涉及：`src/utils/dimensions.ts` — 新增 `computeAchievementMetrics(scores, songMap)` 导出函数
