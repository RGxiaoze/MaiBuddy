# 谱面分析 — 特征定义

> 基于 research/five-dimension-algorithm.md 的位移驱动五维分析框架。
> 本文档为设计定稿，所有公式与参数已确认。

## 前置：坐标与几何模型

### 按键坐标（来自 maimai-layout.ts）

笛卡尔坐标系：原点 = 屏幕中心，归一化半径 = 1.0。

| 按钮 | 角度 | 半径 | (x, y) |
|------|:--:|:--:|------|
| 1 | 22.5° | 1.17 | (+0.448, −1.081) |
| 2 | 67.5° | 1.17 | (+1.081, −0.448) |
| 3 | 112.5° | 1.17 | (+1.081, +0.448) |
| 4 | 157.5° | 1.17 | (+0.448, +1.081) |
| 5 | 202.5° | 1.17 | (−0.448, +1.081) |
| 6 | 247.5° | 1.17 | (−1.081, +0.448) |
| 7 | 292.5° | 1.17 | (−1.081, −0.448) |
| 8 | 337.5° | 1.17 | (−0.448, −1.081) |

触摸区 A/D 半径 = 0.835，B 半径 = 0.42，E 半径 = 0.60，C = (0, 0)。使用 `getPosition(group, index)` 获取坐标。

### Slide 路径

- 不插值，仅直线连接 `SlideSegment.vertices`。
- 多段 Slide（`*` 连接）首尾相接。
- Slide delay 期间手指停留在 startLocation（计入技巧 T6 的并发检测）。
- 每 0.05 秒插入虚拟位置点（线性插值），**仅影响 T1**，不影响其他维度。

### 距离

欧氏距离：`√(dx² + dy²)`。

### 时间间隔

"事件点"模型：所有 NoteCollection.time、Hold 释放 (time+length)、Slide 终点统一排序，Δt = 下一事件时间 − 当前事件时间。处理时间重叠/负间隔防御。

### 手指模型

- 两指追踪。初始位置：右手 = 3，左手 = 6。
- 同帧 2 目标：最小总距离配对（2×2 排列）。
- 同帧 1 目标：最近手指前往，另一指不动。
- 同帧 3+ 目标：匹配 2 个，剩余音符数计入 T7。

## 1. 底力 (Processing)

**定义**：谱面高密度时段内连续处理所有音符的综合能力。

**计算公式**：
```
1. 全曲帧密度：每帧音符数
2. 密度基准线 = P90(全曲帧密度)
3. 高密度帧 = 帧密度 > 基准线的帧
4. processing_raw = 高密度帧的平均位移速度（归一化距离/秒）
```

**归一化**：`min(raw / P95_all, 1.0) × 18`

## 2. 体力 (Stamina)

**定义**：双池消耗模型（肩膀 + 小臂），纯消耗模型（不减去恢复），附元数据标签。

### 舒适区

| 手 | 默认位置 | 舒适区（按键） |
|------|:--:|------|
| 右手 | 3 (112.5°) | 1-4 (22.5°~157.5°) |
| 左手 | 6 (247.5°) | 5-8 (202.5°~337.5°) |

### 每帧消耗

```
对手掌每次位移 D：
  如果目标在舒适区内：
    小臂 += D × 速度
  否则：
    跨区量 = 目标到舒适区边界的最近距离
    小臂 += (D − 跨区量) × 速度
    肩膀 += 跨区量 × 速度

双押帧：小臂消耗 × 1.3
Hold < 0.5s：按 tap 处理
Hold ≥ 0.5s：占用 [time, time+length] 键位
```

### 合并

```
stamina_raw = 肩膀总消耗 + 小臂总消耗
```

### 元数据标签（输出但不影响分数）

- `longest_no_rest_duration`：最长连续高密度段（>6 音/秒）时长
- `rest_density_ratio`：低密度段（<2 音/秒）时长占比
- `num_high_intensity_peaks`：高强度峰值数量

**归一化**：`min(raw / P95_all, 1.0) × 18`

## 3. 爆发 (Burst)

**定义**：极短窗口内峰值位移/密度的最大值，衡量瞬间爆发能力。

**计算公式**：

```
窗口大小 W ∈ {0.3, 0.5, 0.8, 1.0}
滑动步长 = W / 2

每个窗口 [t, t+W]：
  D = Σ 窗口内每帧两指位移之和（归一化单位）
  N = Σ 窗口内每帧音符数

  聚集系数 C：
    0.1s 子窗口扫描 → N_peak = 子窗口最大音符数
    C = N_peak / max(N × 0.1 / W, 1)
    不截断 C

  D_rate = D / W
  N_rate = N × C / W

  D_score = D_rate / D_RATE_CAP       // D_RATE_CAP = 6.0
  N_score = N_rate / N_RATE_CAP       // N_RATE_CAP = 16.0

  window_score = max(D_score, N_score) + 0.3 × min(D_score, N_score)

burst_raw = 所有窗口、所有 W 中 window_score 的最大值
```

快捷键：Slide 虚拟中间点**不进入**爆发窗口。

**归一化**：`min(raw / P95_all, 1.0) × 18`

## 4. 定位 (Positioning)

**定义**：两个子维度的等权合并 — 5a（高密度时间平均位移速度）+ 5b（每次跳跃的速度 × 方向难度 × 触摸系数）。

### 5a — 高密度平均位移速度

```
窗口定义：与底力相同（全曲帧密度 P90 基准线以上）
5a_raw = 高密度帧的平均位移速度（归一化距离/秒）
```

### 5b — 跳跃难度

```
对全曲所有帧的每次手指位移：
  方向判定（按角度差）：
    从下往上  → ×1.3
    横向（-15°~+15°）→ ×1.0
    从上往下  → ×0.8
    过底 4↔5  → +0.2
  
  触摸系数：涉及触摸区时 ×1.2

  单次跳跃得分 = 速度 × 方向系数 × 触摸系数

5b_raw = mean(所有跳跃得分)
```

### 合并

```
5a_normalized = min(5a_raw / P95_5a, 1.0) × 18
5b_normalized = min(5b_raw / P95_5b, 1.0) × 18
positioning = (5a_normalized + 5b_normalized) / 2
```

## 5. 技巧 (Technique)

**定义**：综合协调能力，三层结构。

### 层结构

| 层 | 子要素 | 层内权重 | 层间权重 |
|------|------|:--:|:--:|
| **Path** | T1 + T2 | 0.7 / 0.3 | 0.4 |
| **Composite** | T3 + T6 + T7 | 0.4 / 0.4 / 0.2 | 0.4 |
| **Special** | T5 + T8 | 0.5 / 0.5 | 0.2 |

### T1 — Slide 路径速率

```
T1 = (Σ 每个Slide 的 vertices 直线总长 × SlideType 放大系数) / 谱面总时长

SlideType 放大系数：
  StraightLine (−)              → 1.0
  CurveCw / CurveCcw            → 1.3
  Fold (v / V)                  → 1.4
  RingCw / RingCcw              → 1.5
  ZigZagS / ZigZagZ (s / z)     → 1.2
  Fan                           → 1.2
  p (绕圈星星)                  → 1.6
  EdgeFold / EdgeCurve*         → 1.3

含 Slide 虚拟中间点（每 0.05s 一个），仅影响 T1。
```

### T2 — SlideType 多样性

```
T2_score = min(种类数 / 5, 1.0)
```

### T3 — Touch 复合

```
T3_score = min(同帧 Touch+按键帧数 / 总帧数 / 0.05, 1.0)
```

### T5 — 折返扫键段

检测规则：连续 3+ 键单向扫键后立即反向（方向变化 ≥135°），反向起点与正扫终点相同或相邻（≤1 键）。

```
T5 = 折返扫键段数量
```

### T6 — delay 并发复杂度

Slide delay 期间检测并发音符，记录：并发音符数、与起始键平均距离、是否跨手。

```
每次 delay 事件得分 = 并发音符数 × 平均距离 × 跨手系数(1.5 if 跨手 else 1.0)
T6 = mean(所有 delay 事件得分)
```

### T7 — 超额音符密度

```
T7 = Σ(每帧超出 2 个的音符数) / 总帧数
```

### T8 — 变速点数量

```
T8_score = min(变速次数 / 10, 1.0)
```

### 合并

```
Path      = T1_n × 0.7 + T2_s × 0.3
Composite = T3_s × 0.4 + T6_n × 0.4 + T7_n × 0.2
Special   = T5_n × 0.5 + T8_s × 0.5

tech_raw = Path × 0.4 + Composite × 0.4 + Special × 0.2
```

各子要素先各自归一化（P95 或映射公式如 `min(x/cap, 1.0)`），再层间合并。

**归一化**：`min(raw / P95_all, 1.0) × 18`

---

## 归一化策略

- 所有维度映射到 **0–18** 区间。
- 全库混池取 P95（不分难度级别）。
- 每首曲目的不同难度完全独立计算。
- 归一化公式：`min(raw / P95_all, 1.0) × 18`。
