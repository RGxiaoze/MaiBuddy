# 谱面分析 — 构建流程

## 脚本架构（伪代码）

```
extract-features.js:
  1. 扫描 参考谱面/ 目录下所有 .txt 文件
  2. 对每个文件:
     a. 解析 simai 元数据头 (title, bpm, artist, version)
     b. 按难度分割 (lv_0 ~ lv_4)
     c. 对每个难度:
        - 用 simai-sharp-ts 解析谱面数据为 NoteCollection
        - 提取底层特征（密度序列、位移序列、休息段等）
        - 计算五维原始值
        - 按难度级别分组
  3. 遍历全部谱面后:
     a. 统计各维度分布 (min, max, p50, p95, p99)
     b. 计算归一化参数
     c. 对每个谱面重新归一化
  4. 输出 public/data/simai_features.json

格式: {
  "songs": {
    "PANDORA PARADOXXX[SD]": {
      "lv_3": {  // Master
        "raw": { "processing": 1200, "stamina": 800, ... },
        "normalized": { "processing": 8.5, "stamina": 6.2, ... }
      }
    }
  },
  "norms": { "processing": 1500, "stamina": 1200, ... },
  "stats": { "processing": { "min": 0, "max": 1500, "p95": 1400, ... } }
}
```

## 依赖包

| 包 | 用途 |
|-----|------|
| `simai-sharp-ts` | simai 谱面解析（已安装） |
| `fs` / `path` | 文件遍历 |
| `glob` | 可选，简化文件匹配 |

## 构建命令

```bash
node scripts/extract-features.cjs
```

## 输出

- `public/data/simai_features.json` — 前端加载使用
- `.gitignore` 排除此文件（prebuild 时自动生成）
