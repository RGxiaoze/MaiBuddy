# 谱面分析 — 集成方案

## 前端加载

`public/data/simai_features.json` 在应用启动时通过 `fetch()` 加载:

```ts
// src/services/simaiService.ts (新建)
export async function loadSimaiFeatures() {
  const res = await fetch(import.meta.env.BASE_URL + 'data/simai_features.json')
  return res.json()
}
```

## 与 songStore 合并

特征数据按曲名 + 难度索引与 `songStore` 的曲目数据关联:

```
songStore.Song (id, title, difficulties[levelIndex])
         +
simai_features.songs["曲名[类型]"]["lv_N"]
         ↓
dimensions.ts: computeChartDimensions() 可直接使用位移特征值
```

匹配键: `曲名 + [类型标记]` ≈ `song.title + [song.type]`

## 五维计算融合

### 当前方案（物量统计）
```ts
computeChartDimensions(chart, bpm):
  processing = bpm × total / NORM
  stamina = total² / (bpm/60) / NORM
  burst = bpm² / 40 / NORM
  positioning = (slide×0.5 + hold×0.7) / total / NORM
  technique = (slide×0.7 + touch×0.3) / total / NORM
```

### 新方案（位移驱动）
```ts
computeChartDimensions(chart, bpm, simaiFeatures?):
  if (simaiFeatures) {
    // 直接使用预计算的特征值（已归一化）
    return simaiFeatures.normalized
  }
  // 降级到物量统计
  return legacyCalculation(chart, bpm)
```

## 降级策略

| 情况 | 处理 |
|------|------|
| 无 simai 特征数据 | 使用现有物量统计算法 |
| 特征值为 0 | 使用物量统计值 |
| JSON 加载失败 | 静默降级，不影响页面渲染 |
