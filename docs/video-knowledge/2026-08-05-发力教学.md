## 核心内容：五部位发力体系

| 部位 | 要点 | 适用配置 |
|------|------|------|
| **指尖** | 固定其余部位，仅指尖上下摆动 | 最精细敲击 |
| **手腕** | 指尖手背放松，手腕抬起自然下垂敲击 | 双单双单、对角双押 |
| **手背** | 手腕基础上固定手型（弓形/握鸡蛋状），更精准不易拍框 | 抓绝赞/低差分准度 |
| **小臂** | 位移需求时摆动；**仅高速交互等底力爆发配置才绷紧**，平时是支撑点 | 交互、扫键 |
| **大臂** | 大部分时间完全放松；仅出张和转圈等大幅度配置 | 出张、转圈 |

## 关键观点

1. **越级错发力**：底力不够时本应用手腕却用大臂 → 容易拉伤（"身体跟不上意识"）
2. **减少多余动作**：高等级体力不足的主因之一；越级时大臂绷紧最常见
3. **重心放低 + 放松手臂**：出张配置接不住时推荐
4. **发力点偏移**：拍框时发力点略微朝第一指关节偏移
5. **练习推荐**：L9（13+）慢速轴交互——避免拍框训练
6. **推分策略**：全3S底力提升微乎其微；推荐单曲 100.8+ / AP；AP 后期再追求

## 对五维模型的启示

- **体力**：小臂/大臂的"正确使用边界"可量化——越级谱面（体力不足）会导致错误发力，与体力维度的"舒适区"模型吻合
- **底力**：高速交互 = 小臂绷紧段，对应等效 BPM 高值区
- **爆发**：小臂仅爆发配置才绷紧 → 支持"爆发是小臂瞬时发力"的假设
