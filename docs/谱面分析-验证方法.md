# 谱面分析 — 验证方法

## 单元测试

### 单个谱面验证
1. 手动选择一个已知谱面（如 PANDORA PARADOXXX Master）
2. 运行特征提取，输出原始值
3. 与手动计算对比（如手工统计高密度段音符数）

### 批量回归测试
- 存储上一次构建的 `simai_features.json` 作为 baseline
- 每次修改特征算法后，对比新旧输出
- 差异超过阈值（如归一化值偏差 > 0.5）标记为异常

## 异常值检测

| 规则 | 处理 |
|------|------|
| 密度 = 0（空谱面） | 跳过该难度 |
| 定数 = 0（无定数数据的谱面） | 降级使用难度等级推定 |
| BPM = 0 | 使用默认值 120 |
| 归一化后值 > 10 | 标记为天花板，标注警告 |
| 归一化后值 < 0.1 | 检查是否为空谱面或解析失败 |

## 与社区评分的相关性验证

对每个维度计算:
- Pearson 相关系数（特征值 vs 官方定数）
- Spearman 秩相关系数（特征值 vs Diving-Fish 拟合定数）
- 预期: 底力/爆发与定数强相关(>0.7), 技巧/定位中等相关(>0.4)

## 人工抽检

每轮构建后随机抽检 5 首谱面:
1. 打开原始 simai 文件，用肉眼判断 "这个谱面体力消耗大概多少"
2. 对比特征输出，看是否合理
3. 异常谱面记录到 `docs/谱面分析-异常记录.md`
